## 最终结果

| 用例 | 预期 | 实际证据门控 | 选择文档 | 应用层模型调用 | API 总耗时 | 结论 |

## 运行中发现并修复的问题

401 用例首次运行时，意图被正确识别为 `technical_login`，但置信度为 `0.715`，低于旧的 `0.8` 预取阈值，导致生成模型跳过 RAG。修复后，所有具体业务意图均执行一次确定性知识预取；候选是否充分由后续证据门控判断。预取完成后移除 RAG 工具，避免生成模型重复检索。

修复后的全量自动化回归结果为 `138 passed`。

## 边界

- 三条样本只能证明关键分支可运行，不能推导总体准确率。
- 401 回答虽然证据选择正确，但同时结合了 Technical Skill 中的通用排查规范，篇幅和场景聚焦仍可优化。
- 本轮没有验证供应商超时、限流、断网和无效 JSON 的真实故障；这些分支仅由自动化测试覆盖。
