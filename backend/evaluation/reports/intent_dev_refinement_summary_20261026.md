# 意图识别开发集修复记录

## 修复对象

首次冻结测试 v1 暴露出两类问题：通用 `query` 过度吸收业务专类，以及 Pattern 无法理解“没有崩溃”等否定表达。本轮只使用人工确认的开发样本进行修复，没有重新运行冻结测试 v1。

## 代码调整

1. 将 `query`、`request`、`billing`、`technical` 的 Few-shot 改为与各自定义一致的通用示例，移除订单、退款、发票、登录、崩溃等跨类示例。
2. 明确 `billing` 包含套餐价格、收费规则和续费费用。
3. 明确 `other` 包含汇率、天气、推荐和通用知识等客服范围外问题，并补充 `other` Few-shot。
4. 为崩溃关键词增加否定作用域识别；“没有、并未、不存在、不会”等否定表达不再触发 `technical_crash`。
5. 将无明确错误码的“报错”归入一般 `technical` Pattern；`500`、崩溃和闪退仍属于 `technical_crash`。
