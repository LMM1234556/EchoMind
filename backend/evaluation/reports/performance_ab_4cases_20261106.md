# EchoMind 四题性能配对报告

执行：2026-11-06。人工复核确认：2026-11-07。

## 实验目标与设计

验证关闭结构化任务思考后，四个既定复合诉求能否继续完成目标，并比较 Token 与端到端耗时。

| 条件 | 设置 |
|---|---|
| 业务代码 | d097b2bd6b55679f5058ea66a0ffd73ca815a626 |
| 模型 | qwen3.6-plus，供应商别名 |
| 知识库 | 六篇相同冻结业务文档 |
| 问题 | 原覆盖集的 048、049、051、052 |
| 控制组 | 全部组件保持供应商默认思考配置 |
| 优化组 | 意图识别、证据选择、画像提取关闭思考 |
| 最终回复 | 两组保持同一默认配置 |
| 隔离 | 两组使用全新、互不重叠的用户与会话 |
| 历史检查 | 各组运行前 Redis 键数为 0，运行后各会话两条消息 |
| 执行顺序 | 控制组四条，随后优化组四条 |
| 自动重试 / 换模 / Judge | 均为 0 |
| usage | 38 次调用完整返回，累计 58,916 Token |

## 总体结果

| 指标 | 控制组 | 优化组 | 变化 |
|---|---:|---:|---:|
| 目标任务人工复核 | 4/4 通过 | 4/4 通过 | 目标均完成 |
| 供应商调用 | 19 | 19 | 相同 |
| 输入 Token | 16,913 | 17,049 | +0.8% |
| 输出 Token | 19,904 | 5,050 | -74.6% |
| 总 Token | 36,817 | 22,099 | **-40.0%** |
| 平均端到端耗时 | 82.22 秒 | 34.77 秒 | **-57.7%** |
| 中位端到端耗时 | 77.37 秒 | 36.96 秒 | -52.2% |

总 Token 包含前台处理和后台画像调用；端到端耗时采用目标 HTTP 请求的外部计时。后台画像在返回后继续运行，由运行器等待排空并计入 usage。

## 逐题结果

| 原题 | 控制组 Token | 优化组 Token | 控制组耗时 | 优化组耗时 | 关键验收 |
|---|---:|---:|---:|---:|---|
| 048 | 10,838 | 5,651 | 105.44 秒 | 44.86 秒 | 回答手机重置密码，说明发票时限需核实 |
| 049 | 7,977 | 5,193 | 68.72 秒 | 29.07 秒 | 加急运费 15 元，审核通过后 5–7 个工作日到账 |
| 051 | 8,937 | 6,651 | 76.95 秒 | 46.47 秒 | 401 认证失败排查，100 积分抵 1 元 |
| 052 | 9,065 | 4,604 | 77.78 秒 | 18.69 秒 | 标准配送 3–5 个工作日，异常订单提供订单号 |

两组的四个回答均经过证据核对，并由项目负责人确认。支持文档和知识缺口状态保持一致：048 为部分支持，其余三条为双主题充分证据。

## 组件归因

| 组件 | 控制组 Token | 优化组 Token | 变化 |
|---|---:|---:|---:|
| 意图识别 | 11,578 | 3,703 | -68.0% |
| 证据选择 | 7,252 | 2,633 | -63.7% |
| 画像提取 | 3,630 | 1,281 | -64.7% |
| 最终 Agent | 14,357 | 14,482 | +0.9% |
| 合计 | 36,817 | 22,099 | -40.0% |

被调整的三个组件合计 22,460 → 7,617 Token（减少 66.1%）。其输出从 15,774 降至 796 Token（减少 95.0%），最终 Agent 的总用量基本保持一致。

计算方式：减少比例 = (控制组 − 优化组) / 控制组。输入、输出及总 Token 均取供应商返回 usage；费用根据相应计价另行计算。

## 采用与后续验证

组件级策略进入当前实现。结果适用范围为这四个固定复合诉求，验收由项目负责人结合证据完成。固定执行顺序使延迟可能受供应商时段负载影响；后续扩展以更多场景、重复运行和交错顺序检查稳定性。

该记录与原 60 条首次回答覆盖基线分开保存，便于分别复核覆盖诊断和定向改动效果。
