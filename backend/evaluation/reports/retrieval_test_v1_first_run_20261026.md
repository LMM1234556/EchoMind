## 结论

本次独立受控结果表明，BGE 在中文检索排序上明显优于 MiniLM：Hit@1 从 55.56% 提升至 97.22%，MRR@6 从 70.79% 提升至 98.61%。加入开发集固定阈值后，包含知识缺口拒答的严格 Decision Accuracy 从 35.00% 提升至 78.33%。

同时，BGE 不是完整的证据判定器。它的业务难负例拒答率只有 8.33%，说明后续仍需依赖意图-文档映射、文档覆盖检查或专门的证据判别层，不能把“最相近文档”直接等同于“文档能够回答”。

## 表述边界

本报告评估的是六篇演示文档上的 Embedding 检索层，不包含查询改写、关键词融合、LLM 重排、Agent 生成回答或线上流量。不能将结果写成“完整 RAG 准确率从 65% 提升至 83%”，也不能声称生产准确率达到 97.22%。可如实表述为：在 60 条人工审核合成查询的冻结对照中，BGE 相比 MiniLM 将 Hit@1 从 55.56% 提升至 97.22%，严格证据决策准确率从 35.00% 提升至 78.33%。

测试结果现已揭示，不得依据上述 60 条题目修改本次阈值、模型、语料或检索规则。若继续优化知识缺口识别，必须使用新的开发样本，并建立新的冻结测试集验证。
