# 复合诉求分项取证

实现日期：2026-11-06；定向回归与人工复核已完成。

## 问题与方案

60 条覆盖基线中，8 条复合诉求严格通过 1 条。典型表现为一条消息包含两个问题，检索链路仅保留单篇证据，另一项规则因此漏答。

改进使用确定性子句拆分、分项检索和并行证据选择。每个子问题保留自己的来源与状态，生成阶段逐项组织回复。

## 实现要点

1. 明确分隔符和不同知识主题共同触发拆分。
2. 子问题分别运行检索、标题检查与 Evidence Selector。
3. 并行执行分项取证，最多保留三篇最终证据。
4. 有证据的部分回答事实，资料缺口部分提供核实路径。
5. 单一主题或分隔依据不明确的输入继续使用原处理方式。

对应源码：[查询拆分](../backend/core/knowledge_routing.py)、[检索工具](../backend/agents/tools.py)、[回复整合](../backend/agents/agent_orchestrator.py)。
