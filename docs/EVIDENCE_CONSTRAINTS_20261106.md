# Skills 与业务证据的事实约束

验证日期：2026-11-06。

## 问题与调整

旧开发题的退款回复正确给出了审核与到账时效，同时增加了选中文档未提供的“仓库确认收货后才进入审核”条件。检查发现账单 Skill 包含支付渠道差异、特殊订单处理等具体说明，加载提示又要求优先遵循这些业务规则，容易使服务规范与政策证据混用。

本次明确两类输入的职责：Skills 提供服务方法、必要信息核验和安全要求；平台时效、费用、资格、退款路径及流程先后关系，由本轮已验证知识证据或真实工具结果支持。

调整包括：

- Skills 加载提示明确政策证据优先，示例话术本身也需要证据支持。
- 账单 Skill 采用“规则咨询、交易核验、实际办理”三类服务方法，纯政策咨询直接回答已知规则。
- Agent 事实约束要求逐项检查流程关系和新增条件，保留原文的阶段含义与适用范围。
- 发往生成模型的证据包继续只包含一篇最终选中文档，并补充流程关系和答复范围约束。

知识库六篇演示文档及评测题目保持原有内容。
