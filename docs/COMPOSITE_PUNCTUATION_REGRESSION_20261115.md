## 问题与定位

用户提问：

> 密码忘了怎么重置？还有，发票申请后多久能开好？

原回复仅说明缺少业务依据，遗漏了密码重置指引。运行 Trace 显示，知识预取按整句和发票意图处理，最终证据为空。

根因在分句：问号和逗号使“还有”成为独立片段；主题检查将其视为未知诉求，于是保留整句查询。修复后只跳过完整匹配的独立连接词，仍保留带实际内容的未知诉求检查。两个子问题分别取证，账户安全文档支持密码重置，发票时限保留知识缺口。

该场景由现有 Billing Agent 的账户职责承接。是否完成任务，以诉求覆盖和证据支持判断。
