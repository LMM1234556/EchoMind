# 工程变更摘要

## 模型接入

- 支持通过 `ANTHROPIC_BASE_URL`、`ANTHROPIC_MODEL` 和 `ANTHROPIC_API_KEY` 接入 Anthropic 兼容服务。
- 当前环境使用阿里云百炼 Qwen 模型；密钥只保存在本地 `.env` 文件中。
- 对连接、超时、限流和 HTTP 状态错误进行分类，避免无意义的同提供商重复回退。

## Agent 路由与工具调用

- 修正工具调用完成后丢失工具轨迹的问题。
- 对同时包含账单和技术问题的宽泛请求，优先并行调用 Billing 与 Technical Agent，避免额外调用 General Agent。
- 保留紧急事件和人工升级路由的优先级。
- 工具仅在模型主动调用或确定性预取条件满足时执行；“提供工具”不代表“工具已被调用”。

## RAG 与知识库

- 增加知识库检索门控，避免无关问题触发 RAG。
- 支持快速关键词召回，并在需要时回退到完整检索流程。
- 增加候选合并、去重、Top-K 选择和检索评测逻辑。
- 修正 ChromaDB 中用户与会话的组合过滤。

## 会话记忆

- 使用 Redis 保存短期工作记忆，并设置窗口和 TTL。
- 使用 ChromaDB 保存情景记忆和用户画像。
- 修正长对话压缩后的时间顺序，以及同一用户不同会话之间的隔离。

## 监控与可观测性

- 对同一指标和 Agent 的活动告警去重，并在恢复后关闭告警。
- 将 Agent 延迟告警阈值改为可配置项 `AGENT_LATENCY_WARNING_MS`。
- 记录记忆读取、意图识别、各 Agent、并行阶段、回复合成、记忆写入和 API 总耗时。
- 前端显示最近请求的路由、工具轨迹与阶段耗时。

## 测试

- 补充 Agent 路由、知识库、RAG 门控、会话记忆、工具管理、监控和检索评测测试。
- 真实外部模型调用不纳入普通自动化测试，避免无意消耗额度；需要单独进行受控验证。
