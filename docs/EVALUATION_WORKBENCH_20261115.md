# 评测证据输入与工作台验证

实现准备于 2026-11-13，完整回归核对于 2026-11-15。

## 改进目标

让维护者分别查看意图分类表现、对话辅助评分和逐题验收材料。政策类评分由评测者提供的业务证据与验收条件支持，人工复核继续负责最终质量结论。

## 交付

1. 对话用例新增 `case_id`、`reference_evidence` 与 `acceptance_criteria`，从 API 传到 Judge，并保留在结果中。
2. 内置五组对话以版本化演示业务文档作为独立参考，按每题条件检查。
3. 工作台分别展示意图准确率、对话辅助评分达标数、评分异常与待人工验收数量。
4. 逐题展示问题、回答、参考文档、验收条件与评分状态；均分量尺统一为 0–1。
5. 缺失维度、字符串、布尔值、越界数值、NaN 与 Infinity 记为评分异常；异常留在计数中，均分采用有效评分。
6. 默认用户与会话逐次生成新标识，多轮组内共享上下文。
7. 用例、参考证据、量表、阈值和评分提示词进入指纹，指纹一致时进行相邻运行指标比较。
